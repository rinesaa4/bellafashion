# BellaFashion — React

## Nisja e projektit
1. Instalo Node.js nëse nuk e ke.
2. Hape folderin në VS Code.
3. Në terminal ekzekuto:

```bash
npm install
npm run dev
```

4. Hape adresën lokale që shfaq Vite në terminal.

## Çka përfshin
- Katalog produktesh dhe filtrim sipas kategorisë
- Faqe të detajeve të produktit
- Zgjedhje të ngjyrës dhe madhësisë
- Shportë me sasi dhe largim produktesh
- Formular për porosi
- Dizajn responsive për telefon dhe desktop

## E rëndësishme
Ky është frontend demonstrues. Formulari nuk ruan porositë në databazë dhe nuk dërgon email. Për shitje reale duhet të lidhet me backend/API dhe të konfigurohet mënyra e pranimit të porosive. Fotografitë e produkteve janë shembull dhe mund t'i zëvendësosh me fotografitë e tua.
